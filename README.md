# English Pattern Lab

英語の文法の「型」を選び、単語をタップして英文を組み立てる学習Webアプリのプロトタイプです。

## できること
- 中学英語 / 高校英語 / 日常会話の切り替え
- 文法パターンの選択
- 動詞・目的語・時間・場所などをタップして英文を作成
- ブラウザの音声読み上げで英文を確認
- 作った英文を端末の localStorage に保存
- スマホ対応レスポンシブ UI

## 文法パターン（対応単元一覧）

### 📘 中学英語
1. **be動詞**（現在形・過去形 / is, am, are, was, were）
2. **一般動詞**（現在形・過去形 / 3人称単数現在 etc.）
3. **進行形**（現在進行形・過去進行形）
4. **助動詞**（can, will, must, may, should, shall etc.）
5. **未来表現**（be going to, will）
6. **名詞・代名詞**（人称代名詞, 指示代名詞, 不定代名詞 etc.）
7. **形容詞・副詞**（使い方, 位置, 数量を表す表現）
8. **疑問詞**（who, what, when, where, why, how, which, whose）
9. **命令文・感嘆文**（祈願文, Let's ~ など含む）
10. **接続詞**（and, but, or, so, because, when, if, that etc.）
11. **不定詞**（名詞的用法・形容詞的用法・副詞的用法 / It is ... for ~ to ... / tell A to do など）
12. **動名詞**（主語・目的語・補語になる動名詞 / 不定詞との使い分け）
13. **比較**（原級 as...as, 比較級 -er/more, 最上級 -est/most）
14. **受動態（受動形）**（受け身の表現, by 以外の前置詞）
15. **現在完了形**（継続・経験・完了・結果）
16. **関係代名詞**（主格・目的格・所有格 / who, which, that）
17. **後置修飾**（分詞の前置・後置修飾, 接触節）

### 📙 高校英語
1. **文型と動詞**（SV, SVC, SVO, SVOO, SVOC / 自動詞と他動詞）
2. **時制**（完了進行形, 未来完了形, 時・条件を表す副詞節）
3. **助動詞の応用**（助動詞＋have＋過去分詞, 慣用表現）
4. **受動態の応用**（SVOCの受動態, 句動詞の受動態, 動作と状態）
5. **不定詞の応用**（完了不定詞, 独立不定詞, 意味上の主語, be to構文）
6. **動名詞の応用**（完了動名詞, 意味上の主語, 慣用表現）
7. **分詞**（限定用法・叙述用法, 感情を表す分詞）
8. **分詞構文**（基本・完了形・受動態・独立分詞構文・with＋名詞＋分詞）
9. **関係詞**（非制限用法, what, 前置詞＋関係代名詞, 関係副詞, 複合関係詞）
10. **仮定法**（仮定法過去・過去完了・混合型, I wish, as if, Ifの省略/倒置, 慣用表現）
11. **比較の応用**（the＋比較級, no more than, 比較級を用いた最上級表現 etc.）
12. **否定表現**（部分否定・全体否定, 二重否定, 準否定, 否定文の慣用表現）
13. **強調・倒置・省略・挿入**（強調構文 It is ... that ..., 倒置 etc.）
14. **名詞構文・無生物主語構文**
15. **話法**（直接話法から間接話法への書き換え）
16. **一致と前置詞・接続詞**（主語と動詞の一致, 時制の一致, 複合接続詞）

## Web ページとして公開する方法
`index.html` をそのまま静的 Web サイトとして公開できます。

### GitHub Pages
1. GitHub で新しい Repository を作る
2. `index.html` をアップロード
3. Settings -> Pages -> Deploy from a branch を選択
4. `main` / `root` を選んで Save
5. 数分後に公開 URL が発行されます

### Netlify / Vercel
`index.html` が入ったフォルダをデプロイすれば公開できます。
